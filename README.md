# grokbuildorderproject

Full-stack Order Management / Operations Platform (Educational)

**Purpose**: Upskill to mid-level by building an enterprise order/inventory system with JS/React/Node/TS/Postgres.

Focus: Transactional integrity, workflows, inventory, APIs, architecture, testing.

## Tech Stack
Same as grokbuildhrproject: Node/TS/Express/Prisma/Postgres + React/TS/Vite/TanStack Query.

## Domain
- Products & Inventory
- Orders & Order Items
- Suppliers & Purchase Orders
- Status workflows
